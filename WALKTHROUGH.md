# Assignment 3 Video Walkthrough

Record the real application with your voice. Aim for five to seven minutes.

1. Introduce yourself and COMP229 Assignment 3. Show the local URL and portfolio pages.
2. Create a User account through Sign Up, then sign in. Show its User role and read-only Projects and Education tabs. Explain that editing is also blocked by the API.
3. Sign out and sign in as the provisioned Admin. Show the Admin role and all four resource tabs.
4. Add a fictional project. Edit its title and save. Visit Projects to show the saved database record. Return to Workspace and delete the demonstration record. Repeat a short example for Education.
5. Submit a fictional message through Contact. Return to Admin Workspace and show that it was stored. Demonstrate editing and deleting this disposable contact.
6. Briefly show MongoDB collections and the stored role, keeping password hashes and credentials out of the recording. Explain JWT sign-in, protected routes and token revocation on sign-out.
7. Explain that useState controls the forms and workspace and that successful mutations reload records from the API.
8. Open the final HTTPS deployment. Repeat sign-in and one create/edit/delete flow there. Show /api/health and the Assignment 3 GitHub branch.
