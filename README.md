# Lab Assignment 1 — React Portfolio

## Run locally

1. In this folder, run `npm install`.
2. Run `npm run dev`.
3. Open the local URL Vite displays (usually `http://localhost:5173`).

## Before you submit

- Replace all `Your Name`, contact, education, and project placeholder copy in `src/main.jsx`.
- Replace the About-page photo placeholder with your own professional headshot.
- Put your résumé in `public/resume.pdf` so the download link works.
- Add the project to GitHub with several meaningful commits, then deploy it to Netlify, Vercel, GitHub Pages, or another host.
- Record a short walkthrough showing the site locally and the deployed version.

The contact form captures the submitted form values and sends the user to Home, as required; it does not send email.
